**Create a gmail account + create GCP project**

- In order to start the labs etc we need a temporary gmail account separate from personal use:

<a href="https://support.google.com/mail/answer/56256?hl=en-GB">gmail</a>

- Once a gmail account has been created turn on 2-factor aauthentication along with adding a recovery email + mobile number.  You can do so in Security and sign-in within the gmail account section

![Alt text](images/gcp_create_account_1.png)

- At this point its easier to use incognito and log into 

<a href="https://console.cloud.google.com/">gcp console</a>

- Once you are logged in you can enable the $300 free trial which will last for 90 days
